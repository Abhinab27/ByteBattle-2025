ByteBattle is the official platform for the NIT Silchar national hackathon. It centralizes all aspects of the competition – from registration and team formation to project submission, judging, and results – under one roof.  
Inspired by its motto *“Code, Compete, Conquer,”* the portal delivers a responsive, modern UI (built with Next.js and Tailwind CSS) and a robust Node.js backend.  
📍 [Visit ByteBattle](https://bytebattle.com) *(placeholder – replace with actual domain)*

---

## 🧭 Competition Rounds
The ByteBattle hackathon unfolds in three stages ([Proposal PDF](https://drive.google.com/drive/folders/1qFbqZEvzw1q4-XNIMRS90bAOinRulvIZ?usp=drive_link)):

- **Round 1 (Online – Dec 2025):** Screening quiz with 20 randomized MCQs (Score ≥ 45% qualifies for Round 2).
- **Round 2 (Online – Jan 2026):** Project problem statement, GitHub repository & video demo submission.
- **Round 3 (Offline – Feb 2026 @ NIT Silchar):** 48-hour live coding hackathon with final presentations and cash awards.

## 🧩 Platform Features
ByteBattle offers end-to-end hackathon management:

- ✅ Participant registration and email verification
- 🧑‍🤝‍🧑 Team formation via invite code
- 📦 Project submission: ZIP, GitHub repo, video demo, PDF
- 📊 Real-time scoreboard and judge dashboard
- 📬 Announcements and automated notifications
